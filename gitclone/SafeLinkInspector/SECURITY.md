# Security

SafeLinkInspector is intended for defensive cybersecurity analysis and research.

If you find a security vulnerability in this project, please report it privately by opening an issue or contacting the repository maintainers.

Do not publish sensitive details in public issues.

## Responsible disclosure

- Do not disclose vulnerabilities publicly before the maintainers have had a chance to review them.
- Provide a clear description of the issue and reproduction steps.
- Include the affected version and any relevant environment details.
